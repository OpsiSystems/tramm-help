Sites

Site Classes and Sites — the locations in your logistics network, from depots and warehouses to crossdocks and delivery points.

Sites are the locations in your logistics network — depots, warehouses, crossdocks, and delivery points. Tramm uses a two-layer system: a Site Class acts as a template that defines shared defaults such as operating hours and dwell times, and individual Sites inherit those defaults while being able to override any value that differs for that specific location. This keeps your data consistent without forcing you to repeat the same settings on every site.

What is a Site Class?

A Site Class is a template that defines shared operating hours, dwell times, and attribute rules for a group of similar sites. Rather than configuring each site individually, you set the defaults once on the class and every site in that class inherits them automatically.

For example, a Retail Delivery class might define short entry and exit durations and daytime operating hours — reflecting the reality of dropping off at a shop during trading hours. A Distribution Centre class might define longer operating hours and a higher loading rate, reflecting the heavier handling at a depot.

Any individual site can override the class defaults if that specific location differs from the norm. For instance, one particular retail outlet might have extended trading hours — you can set those hours on the site without touching the class.

The Classes concept applies across several entities in Tramm — not just Sites. See the Getting Started guide for a full explanation of how the Class and instance pattern works.

Site Class Fields

Fields available when adding or editing a Site Class.

Field Required Description
Name Required A descriptive label for this class of sites. Choose a name that reflects the type of location — for example, Retail Delivery, Distribution Centre, or Crossdock.
Operating Hours Optional The default working hours for sites in this class — for example, 08:00–17:00 Monday to Friday. These hours tell the Planner when sites of this type are accessible for deliveries and collections.

Individual sites can override this value if their hours differ from the class default.
Entry Duration Optional The default time required to arrive and set up at a site of this class — also called arrival dwell time. This value is added to the start of each stop in trip time calculations.

Used by the Planner's trip calculation engine. Individual sites can override this with a non-zero value.
Exit Duration Optional The default time required to depart and close off at a site of this class — also called departure dwell time. This value is added to the end of each stop in trip time calculations.

Used by the Planner's trip calculation engine. Individual sites can override this with a non-zero value.
Attributes Optional Custom attributes that are inherited by all sites in this class. Attributes can be used for filtering, reporting, or attribute-based rules.
Restrictions Optional Attribute rules (also called AttributeRules) that constrain which vehicles or products can use sites in this class. For example, you can restrict a Site Class to vehicles with a certain attribute such as Refrigerated, or to products tagged with a specific attribute.

Restrictions defined on the class apply to all sites in that class. Additional restrictions can also be added at the individual site level.

What is a Site?

A Site is an individual location in your network — a depot, warehouse, crossdock, or delivery point. Each site references a Site Class to inherit its defaults, and can override any of those defaults if the specific location requires different values.

Every site has a physical address and GPS coordinates — coordinates are used for route distance and time calculations, and for automatically assigning the site to the correct Region. Sites can also carry contact information, operational instructions for drivers, and a link to a specific client if the site is client-specific.

Site Fields

Fields available when adding or editing a Site.

Field Required Description
Name Required The full name of the site as it will appear in Tramm — for example, Cape Town Distribution Centre or Pick n Pay Rondebosch.
Code Optional A short identifier for the site. Useful when importing data or referencing sites in reports.
Site Class Recommended The Site Class this site belongs to. Selecting a class gives the site its default operating hours, entry duration, and exit duration. While not strictly required, assigning a Site Class is strongly recommended — without one, all time and duration values must be set manually on every site.
Type Optional A type label for the site — for example, Depot, Warehouse, or Delivery Point. Site types are configured in Entity Types in Data Manager, which controls the available options here.
Location Optional The physical address and GPS coordinates of the site. GPS coordinates are used for route distance and travel time calculations. They are also used when auto-assigning the site to a Region based on geographic boundaries.

Enter coordinates as accurately as possible — the Planner calculates road distance and estimated travel times from this position.
Operating Hours Override The operating hours for this specific site. If set, these hours override the Site Class operating hours. If left blank, the system falls back to the class default.
Entry Duration Override Arrival dwell time for this specific site. If set to a non-zero value, this overrides the Site Class Entry Duration. If left at zero, the system uses the class value.

Only set this if the site differs from its class default. See Override Logic for details.
Exit Duration Override Departure dwell time for this specific site. If set to a non-zero value, this overrides the Site Class Exit Duration. If left at zero, the system uses the class value.

Only set this if the site differs from its class default. See Override Logic for details.
Loading Rate Override The loading and unloading speed at this specific site — for example, units per hour. If set, this overrides the class-level loading rate and is used by the Planner when calculating stop durations based on load quantity.
Region(s) Optional The Regions this site belongs to. Regions are used in Lanes for tariff pricing and for geographic reporting. A site can belong to more than one Region.

If GPS coordinates are set, the system can auto-assign the site to the correct Region. If you manage Lanes and tariffs, make sure each site has a Region assigned.
Client Optional If this site belongs to a specific client — for example, a retail chain's own delivery point — link the client here. Client-specific sites can be filtered and reported on by client.
Contact Info Optional Phone number, email address, and physical address for the site. Useful for planners and drivers who need to contact the site directly.
Instructions Optional Free-text operational notes for this site — for example, access gate codes, security procedures, or special delivery instructions. These notes are visible to planners and can be made available to drivers.
Attributes Optional Site-specific attributes, in addition to any attributes inherited from the Site Class. Used for filtering, reporting, and attribute-based restriction rules.
Restrictions Optional Site-specific attribute rules that constrain which vehicles or products can use this site — in addition to any restrictions defined on the Site Class.

How Override Logic Works

The Site Class defines defaults. Individual sites only need values set if they differ from those defaults. The Planner follows a simple fallback rule for Entry Duration, Exit Duration, and Operating Hours.

If a site's Entry Duration is set to a non-zero value, the Planner uses that value for trip calculations. If it is left at zero, the system falls back to the Site Class Entry Duration. The same pattern applies to Exit Duration and Operating Hours — if the site has a value, it takes precedence; otherwise, the class default applies.

This means you only need to set values on the site if they differ from the class defaults. A site that behaves exactly like its class requires no duration or hours overrides at all.

Scenario Retail Delivery class has Entry Duration = 15 min. One site — Woolworths Claremont — requires 30 min to enter due to a parking bay queue.
What to do Set Entry Duration = 30 min on the Woolworths Claremont site only. Leave all other retail sites at zero — they will inherit the 15 min class default.
Result The Planner uses 30 min for Woolworths Claremont and 15 min for every other site in the Retail Delivery class.

Adding a Site Class

Create Site Classes before adding sites. Even if you start with only one class, the class concept makes it easy to update shared settings across many sites later.

  1. Open Data Manager and select Site Classes from the navigation.
  2. Click Add in the toolbar.
  3. Enter a name that describes the type of site — for example, Retail Delivery, Distribution Centre, or Crossdock.
  4. Set Operating Hours for this class — the default hours during which sites of this type are accessible.
  5. Set Entry Duration and Exit Duration — the time it typically takes to arrive at and depart from sites in this class.
  6. Add any shared Attributes or Restrictions if applicable to all sites in this class.
  7. Click Save.
[Screenshot: Add Site Class form]

Adding a Site

Before adding sites, make sure your Site Classes are already set up. The Site Class selection is one of the first fields in the form and sets several defaults for the rest of the form.

  1. Open Data Manager and select Sites from the navigation.
  2. Click Add in the toolbar.
  3. Enter the site name and, if used, a short code.
  4. Select the Site Class. This sets the default operating hours, entry duration, and exit duration for the site.
  5. Select the site type if applicable.
  6. Enter the Location — address and GPS coordinates. Coordinates are used for route calculations and for automatically assigning the site to the correct Region.
  7. Override Operating Hours, Entry Duration, or Exit Duration only if this site differs from its class defaults. Leave these at zero or blank to inherit from the class.
  8. Assign Region(s) if not using automatic region assignment from GPS coordinates.
  9. Link a Client if this is a client-specific site.
  10. Add Contact Info and any operational Instructions for drivers or planners.
  11. Click Save.

Tips & Common Setup Mistakes

Create Site Classes before adding sites

Even if you start with a single class, the class concept makes it easy to update shared settings across many sites later without editing each one individually.

Enter GPS coordinates accurately

Coordinates are used for route distance and travel time calculations, and for automatically assigning sites to Regions. An inaccurate coordinate can result in incorrect distances or a site ending up in the wrong Region.

Set meaningful Entry and Exit Durations

These values directly affect trip timing in the Planner. An incorrect dwell time leads to unrealistic schedules — trips will appear faster or slower than they are in practice.

Common mistake: Entry and Exit Duration left at zero on both the site and its class

If neither the site nor its class has a duration set, the Planner will calculate zero dwell time at that stop. Planned trips will appear faster than they are in practice, and driver schedules will be unrealistic from day one.

Common mistake: Not assigning a Region

If you use Lanes for tariff pricing, sites must be assigned to a Region for the Lane pricing to apply correctly. A site with no Region will not match any Lane, and trip costs may be calculated incorrectly or not at all.
