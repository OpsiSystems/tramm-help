Why Settings First

Before you add vehicles, sites, or products in Data Manager, Settings needs to have the building blocks in place. Two things in particular must be set up first: Dimensions (which define how weight, volume, and size are measured in your system) and Routing Classes (which define the routing profiles used when the Planner calculates routes). Without these, vehicle classes and the planning engine cannot function correctly.

Most settings in Tramm are organisation-wide — configured once and shared across all users. A few preferences are per-user, meaning each user can set their own preference without affecting others.

Dimensions

Dimensions define the units of measurement used throughout Tramm for capacity and size. They are configured in Settings → Definitions → Dimensions. Every capacity figure on a Vehicle Class, every size figure on a Product, and every load calculation in the Planner references a Dimension.

Dimension What it measures Typical unit Used by
weight The mass of goods kg Vehicle capacity, Product size, Load calculations
volume The space goods occupy m³ or L Vehicle capacity, Product size
units The count of items pcs / cartons / pallets Job quantity, Vehicle capacity
length Physical length m Vehicle Physical Size, Product size (3D Visualiser)
width Physical width m Vehicle Physical Size, Product size (3D Visualiser)
height Physical height m Vehicle Physical Size, Product size (3D Visualiser)

Do not rename the standard dimension IDs (weight, length, width, height, units). The Planner and 3D Visualiser reference them by these exact IDs. You can change the display name and unit, but not the ID.

Checking your Dimensions

  1. 1
    Open Settings → Definitions → Dimensions
  2. 2
    Confirm the standard dimensions are present
    Check that weight, volume (or equivalent), units, length, width, and height are all listed.
  3. 3
    Check that units match your operation
    For example: kg for weight, m³ for volume. If your operation uses different units, update the unit label on each dimension — not the ID.
  4. 4
    Add any missing dimensions
    If a dimension is missing, click Add and set the ID, display name, and unit.
  5. 5
    Do not change the IDs of existing standard dimensions
    Renaming an ID (e.g. changing weight to something else) will break references in the Planner and 3D Visualiser.

Routing Classes

A Routing Class is a profile that tells the routing engine how to treat vehicles of a particular type when calculating routes and travel times. It defines the vehicle's physical size constraints, speed limits, road restrictions, and other routing behaviour. Each Vehicle Class in Data Manager is assigned a Routing Class.

A Routing Class is not the same as a Vehicle Class. A Vehicle Class describes a type of vehicle (capacity, costing, operating hours); a Routing Class describes how the routing engine should route that type of vehicle (road restrictions, max speed, hazmat constraints).

Field What it controls
Name Display name — used when assigning to a Vehicle Class (e.g. "Standard Road", "Heavy Vehicle", "Refrigerated")
Length / Width / Height Physical size constraints passed to the routing engine. Affects road and bridge restrictions.
Mass Total vehicle mass. Affects weight-restricted roads.
Transport Mode Road, Rail, or other available modes.
Max Speed Maximum travel speed used for time calculations.
Axle Count Number of axles — affects road restrictions in some regions.
Avoid Features Features to avoid: ferry, tunnel, motorway, toll roads, dirt roads.
Hazardous Goods Types Types of hazardous goods this class can carry (e.g. flammable, toxic, explosive).
Max Trip Duration Maximum allowed trip duration for this vehicle type.
Fatigue Rules Reference to a Fatigue Rule definition (driver rest requirements).

Tramm always falls back to a routing class named Default if no routing class is assigned to a Vehicle Class. Make sure a Default routing class exists — it is used by any vehicle class that does not have a specific routing class set.

Adding a Routing Class

  1. 1
    Open Settings → Definitions → Routing Classes
  2. 2
    Click Add
  3. 3
    Enter a Name that describes the vehicle type
    For example: "Standard Road", "Heavy Vehicle — 56 Tonne". Choose a name that will be recognisable when assigning to Vehicle Classes in Data Manager.
  4. 4
    Set the physical dimensions
    Enter Length, Width, Height, and Mass to match the maximum size for this vehicle type. These values are passed to the routing engine to enforce road and bridge restrictions.
  5. 5
    Set Max Speed if applicable
    Enter the maximum travel speed for this vehicle type. Used by the routing engine to calculate travel times.
  6. 6
    Select any features to avoid
    For example: toll roads, tunnels, ferries. The routing engine will route around these features for any vehicle class that uses this profile.
  7. 7
    Set Hazardous Goods Types if this class carries hazmat
    Select the applicable hazmat categories. The routing engine uses this to apply hazmat road restrictions.
  8. 8
    Assign Fatigue Rules if driver rest rules apply
    Select the relevant Fatigue Rule definition. This controls how the planning engine enforces mandatory rest breaks for this vehicle type.
  9. 9
    Click Commit
  10. 10
    In Data Manager, assign this Routing Class to the relevant Vehicle Classes
    Open each Vehicle Class and select this Routing Class in the Routing Class field on the Specification tab.

Entity Types

Entity Types define the custom type labels that appear in the Type dropdown on vehicles, sites, and other entities. They are configured in Settings → Definitions → Entity Types. Setting up meaningful entity types makes it easier to filter and organise your data in the Planner and other apps.

Examples: for Sites you might define types like Depot, Customer, Crossdock, Port. For Vehicles: Rigid, Horse, Trailer. These are display labels only — they do not affect routing or planning logic.

Entity Types are optional but recommended before adding large volumes of entities.

User Preferences

Some settings are personal — each user can configure these themselves without affecting other users.

Preference What it does Location
Site Address Required When on, the address fields become required when adding or editing a site. Useful for users who want to enforce complete address data. Settings → General → Preferences
Date Range Mode Controls how the date filter works across apps. Static: set your own range. Auto-today: always centres on today. Perpetual: no date restriction. Settings → General → Preferences
Time Zone Sets the time zone used for displaying dates and times in the UI. Settings → General → Preferences
Map Language Primary and secondary language for map labels. Settings → General → Preferences
